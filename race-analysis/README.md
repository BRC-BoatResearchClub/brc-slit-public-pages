## 公開ページ
- [V22 当日24会場の公開出走表](./today.html) — 非公式Boatrace Open API v1をブラウザーから取得（2026年以降）。JST基準の日付・会場・1〜12Rを選択。ページ表示中は5分程度で再取得し、取得できない場合は古い内容を消します。
- [V21 24会場・過去レースのコース別着率](./history-venues.html) — 2015年7月25日〜2026年11月16日の保存済み621,138レースを集計。会場・期間選択、CSV出力。

## 重要な違い
- **V22** は `boatraceopenapi.github.io/api/v1` から取得した出走表です。BOAT RACE公式でもBRC独自分析値でもありません。外部APIには遅延・欠損・誤りの可能性があります。公式情報を優先してください。
- **V21** は保存済みのBRC結果データから独立集計した統計です。V22の公開出走表に結合したり、BRC独自の予測値を算出することはまだしていません。
- **V20** は保存済みの2レースに限る静的スナップショットです。新規の分析計算や毎日の更新は行いません。
- GitHub Pages自体はPythonサーバー・データベース・夜間更新タスクを実行しません。V22の再取得はページ閲覧中にブラウザーが行います。

- 元のトップ `index.html`、`history.html`、`data.json`、ルート `README.md` は変更しない
- 元の非公開データベース・分析Python・認証情報・PC内設定は公開しない
