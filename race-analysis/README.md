## V24の選手別集計について
- BRC保存済みの `races_K.csv`・`boats_K.csv` を使い、2025年11月17日〜2026年11月16日の55,940レース／1,658選手分を集計しました。延べ出走記録は335,062件。選手登録番号をキーにして、当日出走表で選ばれた6選手の記録だけ画面に表示します。
- 着率＝その選手の当該着順回数÷記録された出走数。**全国・全進入コース合算**の値であり、当地限定、枠別・コース別、事前予測、的中確率ではありません。
- この保存データは毎日自動更新されません。少数データは参考値とし、履歴がない選手は「履歴なし」として0%扱いを避けます。
- 2026年11月16日以前の開催日を選んだ場合、この選手別データは選択日以降の結果を含み得るので、バックテストへの未来情報混入を防ぐため非表示にします。
- 公開するのは選手番号別に集約した出走数・1〜3着数の圧縮ファイルだけ。元CSV、Python分析ロジック、認証情報は公開していません。

## 外部APIと他の分析の違い
- 当日出走表は `boatraceopenapi.github.io/api/v1` から取得する**非公式**公開データであり、BOAT RACE公式やBRC内部APIではありません。情報が遅延・欠損する可能性があり、正確性は保証されません。最終確認は公式サイトで行ってください。
- V23/V24の会場別コース着率は、選択会場の**全選手の集合**の過去成績です。V24の選手別全国着率とは分母が異なります。この二つを掛けて予測確率とする処理は実装していません。
- V20は当時保存した2レースの静的スナップショットであり、日次更新や新規の予測計算は行いません。
- GitHub PagesはPythonサーバーや夜間更新タスクを直接実行できません。当日出走表はページ閲覧中に外部APIを再取得します。**BRCの保存済み集計は自動更新されません**。
- 実機のスマホ表示、公開APIからの実データ取得はこのバージョンで未確認です。

## V25の実進入コース別成績
- V24と同じ、2025年11月17日～2026年11月16日の55,940レース／335,062件、登録番号1,658選手分の集計から、実際の進入コース1～6ごとに出走数・1・2・3着数を独立集計しました。
- 表示は選択中の6選手それぞれの全国コース別成績です。枠番による単純な分類ではなく、`boats_K.csv`の`course`を使用。分母はそのコースの記録済み出走数です。
- 選手名をタップすると、その選手の6コースの表が開きます。全6選手の36行CSVも保存できます。出走数20未満は「参考」、出走0回は「履歴なし」と表示します。
- 元のレース結果や予測ロジックはアップロードせず、集計済みの件数を圧縮した`player-courses-v25.b64`のみ公開しています。読み込み時にSHA-256と総出走件数を照合します。
- 過去開催日（2026-11-16以前）では、結果の未来情報混入を防ぐため表示を停止します。2026-11-17以降でも集計日は11月16日のままで、日次更新しません。
- V25は**事前1着率、当日の勝利予測確率、選手の当地限定コース成績**ではありません。実際の非公式API通信の成功・本番スマホでの操作は未検証です。

- **V26**：2025年11月17日～2026年11月16日の保存済み55,940レース、1,658選手、24,914会場×選手組、135,243会場×選手×進入コース組、335,062選手出走記録を集計。公開するのは会場・選手番号・実進入コース別の件数だけで、BRC元DBや認証情報は含めません。

- コース出走が20走未満の着率は少数標本の参考値です。予測確率・当地の予想的中率ではありません。保存データの最終日は2026年11月16日であり、日次更新にはまだ未対応です。
