## 重要な違い
- **V23** の出走表は `boatraceopenapi.github.io/api/v1` から取得した公開データです。BOAT RACE公式でもBRC独自分析値でもありません。外部APIには遅延・欠損・誤りの可能性があります。公式情報を優先してください。実際のAPI取得成功は未確認です。
- **V21** は保存済みのBRC結果データから独立集計した統計です。V23では選択会場のコース着率を隣に表示しますが、**選手個人の着率ではなく、枠番との対応・当日予測も未実装**です。未来情報の混入を避けるため、古い開催日を選んだ際も、この集計で予測のバックテストを行わないでください。
- **V20** は保存済みの2レースに限る静的スナップショットです。新規の分析計算や毎日の更新は行いません。
- GitHub Pages自体はPythonサーバー・データベース・夜間更新タスクを実行しません。V23の出走表取得と5分ごとの再取得はページ閲覧中にブラウザーが行います。V21の過去集計は2026年11月16日で固定です。
