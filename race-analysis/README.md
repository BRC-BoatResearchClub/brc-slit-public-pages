# BRC Race Analysis — スマホ閲覧版

## 公開ページ
- [V20 当日レース分析・保存済み2レース](./index.html) — 2026年11月24日の戸田1R・常滑1Rだけを表示。事前1着率、選手比較、展開別の保存値、CSV出力
- [V21 全国24会場・過去レースのコース別着率](./history-venues.html) — 2015年7月25日〜2026年11月16日までに保存された621,138レースを集計。全期間／直近1年／2026年の切替、会場別検索、CSV出力

## 範囲と制約
- どちらもGitHub Pagesで動作する静的な**保存済み分析結果**です。今後の日付の出走表や分析結果、毎日の自動更新、原本のPython APIによる全条件再計算には対応していません。
- V21の集計元はBRCの保存済み `races_K.csv` と `boats_K.csv` です。V20と集計の出典・期間が異なるため、数値が一致しない場合があります。
- V21の「1着率／2着率／3着率」はコースごとの当該着順数÷そのコースの出走数です。推定的中率や事前1着予測確率ではありません。
- 公開ファイルには元のCSV/DB、分析用Python、認証情報、アクセスキーを含めていません。
- 既存の展示スリットサイトのルート `index.html`、`history.html`、`data.json` は変更していません。

## 今後の拡張
- 全レースの当日分析には、当日出走データと非公開分析APIに相当する更新処理の分離が必要です。
- V20、V21とも保存済みデータの範囲を明示し、新しいデータで更新する際は公開前に個別の検証が必要です。
